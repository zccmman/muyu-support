## 2. 常见问题解答 (FAQ)

### Q1: 敲击没有声音或震动？
- 请检查 iPhone 是否开启了侧边静音开关。
- 请检查系统「设置」->「声音与触感」中是否开启了系统触感反馈。

### Q2: 敲击计数会同步或丢失吗？
- 所有敲击计数与设置均保存在您本地设备中，完全离线可用，不消耗网络流量。

## 3. 隐私政策 (Privacy Policy)

我们极为重视用户的隐私保护：
1. **不收集个人信息**：木鱼 App 为纯本地单机应用，不收集、不存储、不上传您的任何个人身份信息、位置信息或设备标识符。
2. **无需注册登录**：无需创建账户即可使用所有核心功能。
3. **数据安全性**：所有的使用偏好与敲击统计数据仅保存在您的本地设备上。
4. **联系方式**：如有任何隐私相关疑问，请发送邮件至 zccok@icloud.com。
